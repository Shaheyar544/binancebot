# XAU Dashboard

Screens: Overview, Signals, Position/Risk, DCA Review, News/Events, Backtests, Health, Configuration/Pre-flight.

Show price/mark/index, 1D/4H/1H/15M bias, regime, technical/macro scores, position/avg entry/P&L, margin/notional/leverage, liquidation estimate vs user limit, exposure, daily loss/drawdown, news lock, last decision and explanation.

Dashboard controls cannot bypass RiskEngine. UI skills may improve presentation only; never change trading behavior.

For UI work, use emilkowalski skills if installed and keep motion subtle and information-dense.
